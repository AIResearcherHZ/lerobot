## 8. 真机部署一致性要求

SemiTaksT1 真机输入必须与训练一致：双相机（agentview/front + wrist）｜ 8D state ｜ 7D action。

| | EVO1 | SmolVLA |
|---|---|---|
| 分辨率 | 448×448 | 256×256 |
| action | 7D | 7D |
| action chunk | 14（部署覆盖） | 1（checkpoint 原生） |
| gripper | 二值化 (threshold=0.0, ±1) | 不做二值化 |

> `lerobot/libero_plus` 官方数据是 Panda 数据，真机阶段优先用 SemiTaksT1 自采数据训练的 checkpoint。

### 9.2 HIL / DAgger

```
Policy 自主执行 → 即将失败 → 人工接管 → Recovery/Correction → 继续 Policy → 保存 → 重新 Fine-tune
```

迭代 `v1 → rollout+HIL → v2 → rollout+HIL → v3`。重点采集当前 policy 的失败/犹豫/偏移/恢复/纠错，而非大量普通示教。

### 9.3 RA-BC（Reward-Aligned Behavior Cloning）

#### 9.3.1 SARM（需训练）

```bash
pip install -e ".[sarm]"

lerobot-train \
  --dataset.repo_id=local/libero_hdf5 --dataset.root=./demonstration_data/lerobot_v3_alphabet_soup_smolvla \
  --reward_model.type=sarm --reward_model.annotation_mode=single_stage --reward_model.image_key=observation.images.image \
  --output_dir=./outputs/alphabet_soup_sarm --batch_size=32 --steps=5000
```

#### 9.3.2 Robometer（预训练即用，~8GB 显存，推荐）

4B Qwen3-VL backbone，`lerobot/Robometer-4B` 直接用，输出 progress ∈ [0,1] 或 success ∈ {0,1}。

```bash
hf download lerobot/Robometer-4B

python -m lerobot.rewards.robometer.compute_rabc_weights \
  --dataset-repo-id local/libero_plus --dataset-root ./data/libero_plus \
  --reward-model-path lerobot/Robometer-4B \
  --image-key observation.images.front --device cuda
```

#### 9.3.3 TOPReward（零样本，~16GB 显存）

无自身可训练参数，用 `Qwen/Qwen3-VL-8B-Instruct` 算 `log P("True" | video + instruction)`。第一次运行自动下载 VLM 权重（~16GB）。输出是 log-prob 非 progress，需调 `success_threshold`。当前 LeRobot 版本只支持 Qwen3-VL client。

```bash
hf download Qwen/Qwen3-VL-8B-Instruct

python -m lerobot.rewards.topreward.compute_rabc_weights \
  --dataset-repo-id local/libero_plus --dataset-root ./data/libero_plus \
  --num-samples 15 --device cuda
```

两者都生成 `*_progress.parquet`（schema 与 SARM 兼容），后续 RA-BC 命令不变（9.3.6 节）。

#### 9.3.4 Reward Classifier（不适用于 RA-BC）

二分类 success/fail，只输出 0/1，无 dense progress。用途是 HIL-SERL 在线 RL 的成功检测器，**不能**用于 RA-BC 加权。需人工标注成功/失败帧 + 训练（`--reward_model.type=reward_classifier`），无 alphabet soup 现成权重。

#### 9.3.5 计算 RA-BC 权重

```bash
python -m lerobot.rewards.sarm.compute_rabc_weights \
  --dataset-repo-id local/libero_hdf5 \
  --reward-model-path ./outputs/alphabet_soup_sarm/checkpoints/last/pretrained_model \
  --head-mode sparse --num-visualizations 5 --device cuda
```

生成 `sarm_progress.parquet`（列：`index, episode_index, frame_index, progress_sparse, progress_dense`）。

#### 9.3.6 RA-BC 重训

**SmolVLA RA-BC**（官方支持 π0/π0.5/SmolVLA）

```bash
lerobot-train \
  --dataset.repo_id=local/libero_hdf5 --dataset.root=./demonstration_data/lerobot_v3_alphabet_soup_smolvla \
  --policy.type=smolvla --policy.vlm_model_name=./models/SmolVLM2-500M-Instruct \
  --policy.load_vlm_weights=true \
  --policy.path=./outputs/pick_up_the_orange_red_object_and_place_it_in_the_black_box_smolvla_finetune/checkpoints/last/pretrained_model \
  --sample_weighting.type=rabc --sample_weighting.head_mode=sparse --sample_weighting.kappa=0.01 \
  --output_dir=./outputs/pick_up_the_orange_red_object_and_place_it_in_the_black_box_smolvla_rabc --batch_size=4 --steps=30000
```

**EVO1 RA-BC**（如官方后续支持，命令骨架）


## 10. Online RL（当前不支持 VLA 直接做，需外接 RLinf）

LeRobot HIL-SERL 当前是 `GaussianActor + SAC`，**不能** `--policy.type=smolvla --algorithm=sac`。
真 VLA 在线 RL 需外接：`LeRobot(数据/BC/HIL/SARM/RA-BC) → EVO1/SmolVLA → RLinf/RLPD/SAC → LIBERO-plus/SemiTaksT1`。

### 10.1 RLinf 是什么

分布式 RL 训练框架（Ray + Hydra），给 VLA / 具身机器人 / LLM Agent 做真 RL 后训练。算法：PPO / GRPO / SAC / CrossQ / TD3 / IQL / DSRL / OPD / RLT。模型：OpenVLA / OpenPI(π0/π0.5) / GR00T / EVO1 / SmolVLA 等。环境：LIBERO / ManiSkill / IsaacLab / CALVIN / 真机 Franka 等。

### 10.2 更新什么权重

拿 LeRobot 训好的 VLA checkpoint → 加 value head（MLP）→ 用 RL 信号更新：

| 模式 | 训练 | 冻结 |
|---|---|---|
| 默认 PPO/GRPO（`train_expert_only=True`） | action expert + value head + 投影层 | VLM 主体 |
| 全量 RL（`train_expert_only=False`） | VLM + expert + value head 全部 | 无 |
| DSRL（扩散策略+SAC） | 只训轻量 SAC agent（latent noise 空间） | VLM + expert + 投影层全冻结 |

### 10.3 训练流程（PPO 为例）

```
每个 epoch:
  1. 同步权重 Actor → Rollout
  2. Rollout: policy 在环境跑, 收集 (obs, action, reward, logprob, value, done)
  3. 算优势 GAE (γ=0.99, λ=0.95)
  4. Actor 更新: PPO clipped loss, update_epoch=4
  5. 回到 1
```

### 10.4 架构（Ray 分布式四组件）

```
Actor(训练,FSDP/Megatron) → Rollout(推理,HF/SGLang/vLLM) → Env(交互,LIBERO/真机) → Reward(打分,可选)
         ↑                    ↑
    权重每 epoch 同步: Actor → Rollout
```

- **Actor**：持有 policy 权重，算 loss，梯度更新
- **Rollout**：用 policy 推理出 action，收集轨迹
- **Env**：执行 action，返回 obs+reward+done
- **Reward**：算 reward（仿真自带时可省略）

## 11. 最终流程

**EVO1**：SemiTaksT1 Demo → HDF5 → LeRobot v3·448 → Stage1 → Stage2 → LIBERO Eval → 真机
**SmolVLA**：SemiTaksT1 Demo → HDF5 → LeRobot v3·512 → SmolVLA → Vision Encoder Fine-tune → LIBERO Eval → 真机
**Post-training**：BC → HIL/DAgger → SARM → RA-BC → RLinf/RLPD/SAC

注：改n_action_steps会顿挫推理，但是性能消耗小
